# Adaworld另一改进思路

# 报告：面向相变动力学的世界模型——基于前向\-后向不对称性与动作块的时间抽象

## 一、 研究动机：从“保研分岔口”看现有世界模型的局限

在分析AdaWorld等基于潜在动作的世界模型时，我发现当前范式存在一个根本性的假设偏差：**它们假设世界的动力学是齐次且平滑的。**

以我最近的生活为例：在保研结果出来前，我每天的生活轨迹高度重复且可预测（宿舍\-食堂\-图书馆）；但保研结果一旦下达，我未来的发展轨迹将发生根本性的跃迁（去A地读研 vs 去B地工作）。这种现象在动力系统中被称为**“相变”**或**“分岔”**

现有模型（如AdaWorld）通过帧间差分提取Latent Action，面临两个核心痛点：

1. **低维像素陷阱**：在平滑期（每天重复生活），帧间变化太细微，模型容易捕捉噪声而非动作语义；

2. **结构性失明**：在相变期（保研出结果），系统发生不可逆的宏观跃迁，但基于历史帧的模型无法预见这种分岔。传统基于集成分歧的不确定性方法在这里失效，因为分歧只能衡量“多模态的模糊性”，无法衡量“动力学结构的崩塌”。

**核心洞察**：真实世界是**“长程平滑 \+ 稀疏相变”**的混合动力学系统。我们需要让世界模型具备时间抽象能力，并显式感知系统的相变。

---

## 二、 核心改进思路总结

基于上述动机，我提出三个递进的改进思路，将Action Chunk、前向\-后向不对称性与相变检测融合：

### 改进1：动作块——从“求导”到“积分”，逼出语义表征

**思路**：放弃单帧预测（$f_t \rightarrow f_{t+1}$），采用Action Chunk跨越多帧（$f_t \rightarrow f_{t+k}$）。

- **为什么**：单帧差分像是对视频“求导”，极易被高频噪声淹没；拉长预测跨度像是在“积分”，模型无法通过像素平移来作弊，**被迫在Latent Action中编码宏观意图**，从而滤除低维噪声。

### 改进2：前向\-后向不对称性——利用物理因果的“相变雷达”

**思路**：引入后向动力学模型（BDM），与原有的前向动力学模型（FDM）形成对偶。计算不对称性分数 $\mathcal{A} = L_{bwd} - L_{fwd}$。

- **为什么**：现实物理因果是不对称的。杯子摔碎（前向容易，后向极难）。在平滑期，前向后向都好做；但在不可逆的相变点，**后向推断会瞬间崩溃，而前向可能毫无征兆**。这种不对称性的突变，正是我们检测“相变/分岔点”的最天然信号。

### 改进3：混合潜在动作空间与动力学切换——显式建模“保研结果”

**思路**：将原有的单一连续Latent Action解耦为 $z = (z^{cont}, z^{disc})$。$z^{cont}$ 管日常平滑控制，$z^{disc}$ 管宏观相变开关。

- **为什么**：当BDM检测到高不对称性（相变发生）时，触发离散的 $z^{disc}$，强制模型**切换动力学模式**（重采样宏观状态），而不是试图用连续变量去拟合不可逆的轨迹跃迁。

## 三、 改进实现框架

在AdaWorld的基础上，我们的架构（暂定名：**BifurcationWorld**）进行如下重构：

### 1\. 输入与编码层

- **输入**：视频片段对 $(f_{t:t+k}, f_{t+k:t+2k})$，替代原有的单帧对。

- **共享编码器**：采用预训练的基础模型（如DINOv2或V\-JEPA），将视频编码为语义特征 $(s_t, s_{t+k})$，从源头规避像素级噪声。

### 2\. 混合逆动力学模型

- **输入**：$(s_t, s_{t+k})$

- **输出**：混合动作 $z = (z^{cont}, z^{disc})$

    - $z^{cont}$：连续变量，通过 $\beta$\-VAE瓶颈提取平滑变化意图。

    - $z^{disc}$：离散变量，通过Gumbel\-Softmax提取相变类别。

### 3\. 对偶动力学模型

- **前向动力学（FDM）**：$\hat{s}_{t+k} = \text{FDM}(s_t, z^{cont})$，在Chunk内自回归预测。

- **后向动力学（BDM）**：$\hat{s}_t = \text{BDM}(s_{t+k}, z^{cont})$，从未来反推过去。

### 4\. 相变检测与动力学切换

- **不对称性检测**：计算 $\mathcal{A} = ||\hat{s}_t - s_t||^2 - ||\hat{s}_{t+k} - s_{t+k}||^2$。

- **切换机制**：当 $\mathcal{A} > \tau$ 时，判定为相变点。此时激活 $z^{disc}$，FDM停止当前的平滑推演，从新先验中采样宏观状态，开启新的动力学模式。

### 5\. 损失函数

总损失包含五项，核心是引入**可逆性感知的循环一致性**：

- $L_{FDM}$：前向预测损失

- $L_{BDM}$：后向推断损失

- $L_{cycle}$：$\hat{s}_t = \text{BDM}(\text{FDM}(s_t, z))$，只对不对称性低（可逆）的片段施加强约束，对不可逆片段放松。

- $L_{KL}$：连续与离散动作的信息瓶颈约束。

- $L_{asym}$：自适应加权损失，根据不对称性分数调整各损失的权重。

## 四、 预期效果与实验验证

### 1\. 预期定性效果

- **长程预测不发散**：Action Chunk与动力学切换机制，使得模型在长推演时不会因累积像素误差而崩溃。

- **精准定位关键事件**：BDM的不对称性分数曲线，能精准对齐视频中的“开门”、“掉落”等不可逆事件边界。

- **意图解耦**：$z^{disc}$ 能清晰分离出改变系统宏观状态的动作（如“开始推车”），而 $z^{cont}$ 只负责微调（如“调整握把姿势”）。

### 2\. 定量验证指标

- **视频生成质量**：在长程预测（如50步以上）的FVD（Fréchet Video Distance）指标上显著优于AdaWorld和LAPA。

- **事件边界检测**：计算不对称性分数 $\mathcal{A}$ 与人工标注/环境真实事件边界的F1\-Score。

- **下游控制任务**：在具有明显相变的环境（如DMC Remodel、Minecraft、ALOHA操作）中，使用学到的Latent Action进行规划，计算成功率。

### 3\. 消融实验设计

- Ablation 1：去掉BDM（退化为带Chunk的AdaWorld），验证前向\-后向不对称性的增益。

- Ablation 2：去掉 $z^{disc}$（不进行动力学切换），验证混合动作空间对相变建模的必要性。

- Ablation 3：去掉Cycle Consistency中的可逆性感知权重，验证不可逆约束放松的作用。

你提出的这两个问题非常致命，也非常专业。这就是从“开脑洞”到“做扎实研究”的跨越——**Idea决定了上限，而Task和Objective决定了这篇工作能不能落地被顶会接收。**

## 第一个问题：在什么任务上证明现有模型无法处理相变，且学不好动作标签？

我们要找的任务，必须具备**“长程平滑 \+ 稀疏相变”**的物理特性，并且相变前后的视觉特征和未来轨迹会发生根本性偏离。

**1\. 首选任务：具身操作任务（Contact\-Rich Manipulation，如CALVIN, RLBench）**

- **为什么契合**：机械臂操作是典型的相变系统。

    - **平滑期**：机械臂在空中移动，没有接触，画面变化极小且高度可逆（左移右移）。

    - **相变点**：末端执行器**接触到物体**的瞬间（物理状态改变），或者**开合抓手**的瞬间（约束状态改变）。

- **现有模型的失败模式**：

    - AdaWorld/LAPA在平滑期可能学出一些光流意义的Latent Action；但在接触瞬间，帧间变化剧烈且不可逆，单帧逆动力学模型无法用同一个连续分布去拟合这种突变，导致预测的图像糊成一团，或者Latent Action发生模式崩溃。

- **证明实验设计（诊断实验）**：

    - 在机械臂推门/抓取物体的视频上训练AdaWorld。

    - **指标1**：计算门“开/关”临界帧的FVD（生成质量）和PSNR，对比平滑移动帧，证明现有模型在相变点预测崩溃。

    - **指标2**：可视化AdaWorld学出的连续Latent Action的t\-SNE分布。你会发现对应“空中移动”的动作聚成一团，而对应“接触/抓取”的动作散乱且无法与平滑动作区分，证明其缺乏动作语义的解耦能力。

**2\. 次选任务：开放世界游戏（如Minecraft, CRADLE）**

- **为什么契合**：完美对应你“保研”的类比。

    - **平滑期**：走路、挖矿（画面连续变化）。

    - **相变点**：进入传送门（环境彻底改变）、合成物品（背包UI弹出，离散状态转移）、死亡重生。

- **现有模型的失败模式**：无法预测“进入传送门”后的新世界，因为后验坍缩，模型倾向于预测“继续走在原野上”这种安全但错误的平滑帧。

**总结Task1的策略**：不要泛泛而谈，**选定一个具体的具身环境（如CALVIN的推滑块\+开抽屉任务）**，定量证明AdaWorld在“接触瞬间”和“状态切换”时的前向预测误差剧增，且Latent Action失去语义对应关系。

## 第二个问题：学习出的动作如何应用于下游？模型的学习目标到底是什么？

这是审稿人一定会问的：“你搞出 $z^{cont}$ 和 $z^{disc}$，就算预测得再好，能干嘛？”

**1\. 学习目标的重构**

我们的模型目标不再仅仅是**“重建像素”**，而是**“构建因果状态转移图”**

- $z^{cont}$**（连续平滑动作）**：学习目标是**运动学插值**。它编码的是“如何平滑地从一个状态过渡到另一个状态”。

- $z^{disc}$**（离散相变动作）**：学习目标是**因果状态机切换**。它编码的是“是否触发不可逆事件，改变系统的运行模态”。

**2\. 下游应用：层次化视觉规划**

这是最直接、也最有影响力的下游任务。我们将世界模型作为模拟器，进行从目标倒推的规划。

- **场景描述**：给定当前画面（抽屉关着）和目标画面（抽屉开着且里面的方块在桌上）。

- **我们的模型如何规划（与AdaWorld的本质区别）**：

    - **宏观规划（高层）**：利用 $z^{disc}$。模型从目标状态反向检索，发现必须触发两个离散事件：`Take-Out-Block` 和 `Open-Drawer`。这形成了一个粗粒度的技能链。

    - **微观规划（低层）**：在确定了技能顺序后，利用 $z^{cont}$ 生成具体的运动轨迹（如机械臂靠近抽屉的路径）。

- **优势**：AdaWorld由于没有相变感知和动作解耦，其规划必须在庞大的连续潜空间中盲目采样，极易陷入局部最优（比如一直在抽屉前做无意义的平移）。我们的模型通过 $z^{disc}$ 实现了**自动的技能发现和界面划分**，极大地缩小了搜索空间。

**3\. 下游应用：零样本视频到机器人的动作翻译**

- **场景描述**：给模型一段人类开抽屉的第一人称视频。

- **如何应用**：模型提取人类视频的 $(z^{cont}, z^{disc})$ 序列。由于我们将动作抽象到了语义级别（特别是 $z^{disc}$ 抹除了人手和机械臂的形态差异），我们可以直接将提取出的 $z$ 序列输入到机器人的世界模型中，生成机械臂开抽屉的预测画面，从而实现跨实体的模仿学习。





def motion\_reinforced\_loss\(self, x, loss, c=torch\.exp\(torch\.tensor\(e\)\)\):

"""

计算 Motion Reinforced Loss。

\- x: 视频嵌入序列 \(batch, seq\_len, H, W, C\)

\- loss: 原loss \(batch, seq\_len, H, W, C\)

\- c: 强化超参数 \(e\.g\., torch\.e\)

"""

batch\_size, seq\_len, H\_img, W\_img, C = x\.shape  \# 注意: 这里用 H\_img 以避免与序列 H 混淆



\# 初始化 omega\_0 = 1 \(形状: batch, 1, H, W, C\)

omega\_0 = torch\.ones\_like\(x\[:, 0:1\]\)



if seq\_len \> 1:

\# 并行计算所有帧间差异

diff = torch\.abs\(x\[:, 1:\] \- x\[:, :\-1\]\)  \# 形状: \(batch, seq\_len\-1, H, W, C\)



\# 并行 Softmax: 先扁平化像素维度 \(batch, seq\_len\-1, C\*H\*W\)，然后 Softmax

flattened\_diff = diff\.view\(batch\_size, seq\_len \- 1, \-1\)  \# \(batch, seq\_len\-1, num\_pixels\)

softmax\_diff = F\.softmax\(flattened\_diff, dim=\-1\)  \# Softmax 在像素维度上

softmax\_diff = softmax\_diff\.view\_as\(diff\)  \# 恢复形状



\# 并行计算 omega \(c^\{softmax\_diff\}\)

omega\_tail = torch\.pow\(c, softmax\_diff\)\.to\(omega\_0\.device\)  \# 形状: \(batch, seq\_len\-1, H, W, C\)



\# 拼接 omega\_0 和 omega\_tail

omega = torch\.cat\(\[omega\_0, omega\_tail\], dim=1\)  \# 最终: \(batch, seq\_len, H, W, C\)

else:

omega = omega\_0  \# 如果 seq\_len=1，无差异计算



\# 强化损失

l\_motion = loss \* omega

return l\_motion\.sum\(list\(range\(len\(x\.shape\)\)\)\[2:\]\)

本质就是重建下一帧的时候，用图像差分做一下加权

这个是最naive的做法，因为像素层面的抖动其实是有很多噪声在的，但是效果还不错，比起原版方法，后面可以考虑比如针对语义层面做这种增强
