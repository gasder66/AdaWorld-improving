原始架构核心设计

信息瓶颈：1 个 action_prompt token → 32 维隐向量。Prompt 必须从两帧交互中"压缩"出最关键的动作信息。
编码方式：SpatioTemporal Transformer 让 prompt 与所有 patch 做 attention，隐式地聚合全局信息。
输出接口：z̃ ∈ R32 → 直接作为世界模型的 crossattn + vector 条件。

改进方案核心思路

关键原则：处理能力增强，输出接口不变

新增部分（步骤 2, 4, 5）：检测分割 → 主体级特征 → 时空交互

类比：原始 LAM 的 action_prompt 是"盲人摸象"——1 个 token 必须从全局 attention 中猜测哪里有运动。
改进后：先用检测"看见"每个主体，再让它们交互，最后压缩回 1 个向量——看得更清楚，但说的还是一句话。

接口兼容性分析

原始 LAM：z̃ ∈ R32 → squeeze → (B,1,32) crossattn + (B,32) vector → ✅ 直接兼容
改进方案（单向量输出）：z̃ ∈ R32 → 同样 squeeze → ✅ 完全兼容，无需修改世界模型
多向量输出（已放弃）：z̃ ∈ RA×32 → ❌ 需要重新设计世界模型条件注入方式

五、核心问题与当前判断

问题 1：原始 LAM 的 action_prompt 是否已经足够？

原始设计：1 个 action_prompt 通过 SpatioTemporal Attention 与所有 patch 交互，理论上已经能"看到"所有主体的运动。
我们的假设：多主体运动互相抵消，导致 prompt 无法区分不同主体的动作。
反证：V-JEPA 2 用单向量在复杂场景成功；SpatioTemporal Attention 不会"平均掉"不同位置的运动。
当前判断：该假设未经验证，需要先做实验确认原始 LAM 在多主体场景下是否真的失败。

问题 2：改进方案是否真的比原始方案好？

理论优势：显式分离主体 → 每个主体的特征更精确 → 交互后聚合 → 隐动作更准确
理论风险：检测误差传播、主体数量不确定、聚合丢失信息
当前实验：无监督训练 ARI=0.03，说明即使给了 GT mask，场景级重建损失也不驱动分离
当前判断：改进的有效性未证明，需要新的损失函数（如对象级重建）或新的评估方式

问题 3：如果改进有效，如何与 AdaWorld 衔接？

好消息：改进方案输出 z̃ ∈ R32，与原始 LAM 完全兼容，无需修改世界模型。
衔接方式：直接替换 VideoPredictionEmbedderWithLAMEncoder 中的 LAM 即可。
适配阶段：ActionBook/ActionMLP 的接口也不变，因为隐动作维度仍然是 32。

下一步建议

Step 1：先用原始 LAM 在合成数据上训练，评估多主体场景下的隐动作质量（线性探针、聚类）
Step 2：如果原始 LAM 确实失败，再验证改进方案是否更好
Step 3：如果改进方案有效，直接替换 LAM，世界模型无需任何修改
